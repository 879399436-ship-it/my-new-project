# my-new-project

## 项目简介

`my-new-project` 是一个面向 Python 与 Node.js 技术栈的示例项目，用于演示标准仓库结构与协作规范。

## 快速开始

### 环境要求

- Python 3.10+
- Node.js 18+（可选）
- Git

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/879399436-ship-it/my-new-project.git
cd my-new-project

# Python 虚拟环境（示例）
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# Node.js 依赖（示例）
npm install
```

### 常用命令

```bash
# Python
python -m pytest

# Node.js
npm test
npm run build
```
